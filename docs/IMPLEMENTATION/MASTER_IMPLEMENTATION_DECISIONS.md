| **`OV-04`** | **Tek Seferlik Hub `OWNER` Bootstrap & `CASHIER` Varsayılanı** | Windows Master Hub üzerinde tek seferlik, tekrar kullanılamaz `POST /api/v1/admin/owner/bootstrap` ile ilk `OWNER` atanır ve `hub_metadata` içinde mühürlenir. Yerel `.mmsbak` önbellek hedefi **7 gün**dür ve Drive `30g günlük + 12 takvim ayı aylık + min 1 geçerli COMPLETED_UPLOADED` arşivinden bağımsız çalışır. |
| **`GAP-A01`** | **İkincil Barkod Tam-Yığın Senkronizasyonu** | İstemci `addProductBarcode` / `removeProductBarcode` işlemleri atomik `PRODUCT_UPSERT` Outbox üretir (`deviceId` ile); Hub `SpikeDatabase` `schemaVersion = 4` `ProductBarcodes` tablosuyla v3→v4 migration yapar; mükerrer barkod iki katmanda reddedilir (`409 ERR_DUPLICATE_BARCODE`); `GET /api/v1/products` tüm aktif barkodları döner. |
| **`GAP-A03`** | **E2E Test Güncellemesi (`android_full_e2e_verification_test.dart`)** | Gömülü `android_e2e_secret_token_8899` kaldırılır (`MMS_E2E_DEVICE_TOKEN`); kısmi iade beklentisi `PARTIALLY_REFUNDED` olarak hizalanır; `dbFile.copy` yerine gerçek `VACUUM INTO` sözleşmesi kullanılır; yalnız sentetik test verisi işlenir. |
