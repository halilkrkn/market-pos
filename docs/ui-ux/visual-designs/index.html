MARKET MMS Görsel Tasarım Vitrini

Windows Masaüstü (6 Ekran) ve Mobil (4 Ekran) için üretilmiş HTML/CSS statik/etkileşimli tasarım prototipleri (gerçek Flutter uygulaması değildir).

Görsel Tasarımda Uygulanan Kesin Mimari Değişmezler:

  • INV-01 (Kuruş Standardı): Tüm ekranlarda double yasaktır; tüm tutarlar tamsayı kuruş üzerinden Monospace Tabular olarak ve onaylanan görsel formatta (Örn: 12.50 TL) gösterilmektedir.
  • INV-02 (Ayrık Veritabanı): Windows UI `client_local.db`'ye bağlanır, `market_master.db` erişimi yoktur; anlık Hub durumu rozetle izlenir.
  • INV-04 (Eksi Stok Politikası): Eksi stok "allow"dur; faturası girilmemiş ürünün satışı engellenmez, sarı uyarı rozeti verilir.
  • INV-05 (Banka POS Sınırı): Banka POS cihazlarına otomatik tutar aktarımı yoktur; tutar terminale elle girilir.
  • INV-08 (Nakit + Kart Yalnızca): Pilot aşamasında yalnızca Nakit ve Kredi Kartı vardır; parçalı ödeme MVP dışıdır.
  • INV-09 (Tek Sahip Hesabı): Pilot sürümde kasiyer rol yetkilendirmesi yoktur; bizzat Mağaza Sahibi tek hesapla oturum açar.
